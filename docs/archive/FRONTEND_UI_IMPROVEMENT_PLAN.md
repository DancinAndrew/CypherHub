# CypherHub 前端 UI 改善方案

> 參考：Luma、Eventbrite、Accupass 活動報名平台設計模式

---

## 一、現況問題

1. **僅換色，無排版層次**：深色主題但卡片、區塊堆疊方式雷同
2. **視覺單調**：無 Hero、無節奏變化、section 間距一致
3. **活動卡缺乏視覺焦點**：純文字卡片，無圖片、無日期 badge
4. **活動詳情頁資訊散落**：When/Where/CTA 無明顯分組，無 sticky CTA
5. **篩選器過於搶眼**：佔一整個大 card，壓過活動列表
6. **缺乏設計感**：像 AI 生成的 generic 結果

---

## 二、參考平台設計總結

### Luma
- Hero 簡潔：一句價值主張 + 主 CTA
- 白/淺色主調，深色字，高可讀
- 單頁表單，overlay 處理細節
- 過渡動畫輕量

### Eventbrite
- **活動卡**：圖片在上、標題/日期/地點在下，資訊不壓圖
- **詳情頁**：大圖無遮罩，日期/地點/價格放右側或上層
- **CTA**：主按鈕明顯、高對比
- **探索**：分類、城市、垂直 feed

### Accupass
- 操作簡單，適合非技術用戶
- 地區導航（北/中/南）
- 活動 Banner 為視覺重點

### 共通最佳實踐
1. **Above the fold**：活動名、日期、地點、CTA 不滾動就看見
2. **CTA 重複**：導覽列可 sticky、內文分段後再放 CTA
3. **圖片優先**：活動卡以圖為主，資訊附屬
4. **可掃描**：清晰層級、足夠留白、區塊分明
5. **Mobile first**：60%+ 流量來自手機

## 三、改善方案總覽

### A. 主題與色彩
- **改為淺色主調**（或保留深色但提升對比與留白）
- **主色**：單一主色（如 brand）＋中性灰，避免多色混雜
- **背景**：淺灰 #f8fafc，卡片純白，邊框細

### B. 首頁 (HomeView)

| 項目 | 現況 | 改善後 |
|------|------|--------|
| Hero | 無 | 簡短標語 + 搜尋 bar |
| 篩選 | 整塊 card 佔滿 | 收合式 / 橫向 pills，預設縮起 |
| 活動卡 | 純文字 | 圖片區(含 placeholder) → 日期 badge → 標題 → 地點 → CTA |
| 卡片佈局 | 2 欄均分 | 3 欄(桌面)，圖 16:9，更多 gap |
| Section | 無區分 | 加上「精選活動」「所有活動」等標題 |

### C. 活動詳情頁 (EventDetailView)

| 項目 | 現況 | 改善後 |
|------|------|--------|
| 輪播 | 已有 | 全寬、無文字遮罩 |
| 資訊區 | 單欄堆疊 | **兩欄**：主內容左、sticky 右欄 |
| Sticky 區 | 無 | 日期、時間、地點、主辦、**立即報名** 固定可見 |
| CTA | 內嵌 | 主 CTA 大且固定，隨捲動可見 |
| 區塊 | 平鋪 | 明確 section（時間地點 / 主辦方 / 活動內容 / 票種） |

### D. 導覽與全域

| 項目 | 現況 | 改善後 |
|------|------|--------|
| 導覽 | 基本 | 背景白/淺，border 細 |
| 主 CTA | Login | 主色實心，清楚辨識 |
| 容器 | max-w-6xl | 保持，但內部 gap 加大 |

### E. 表單與元件

| 項目 | 現況 | 改善後 |
|------|------|--------|
| 登入/註冊 | 單 card | 左圖右表 or 置中 card，留白加大 |
| 輸入框 | 深色 | 淺色輸入框，細 border，focus 明顯 |
| 按鈕 | 已有 | 主/次按鈕層次清楚 |
| 卡片 | 深色 | 白底、陰影、細 border |

---

## 四、執行順序

1. **Design tokens**：tailwind 淺色主題、spacing、typography scale
2. **App.vue**：導覽改淺色
3. **HomeView**：Hero + 篩選收合 + 活動卡重排（含圖片區）
4. **EventDetailView**：兩欄佈局 + sticky sidebar + CTA
5. **LoginView / ResetPasswordView**：表單版型與輸入樣式
6. **其餘 views**：Profile、MyTickets、Admin、Organizer 系列
7. **DynamicForm**：表單欄位樣式
